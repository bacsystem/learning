# E1 Taxonomía SERUMS

**Objetivo:** modelar profesiones (especialidades), áreas (asignaturas), temas y el peso de cada uno en el examen SERUMS real.
**Valor:** sin taxonomía no hay dominio por área ni plan. Es la base de todas las demás épicas.

| Historia | Título | Fase | Pts |
|---|---|---|---|
| SIA-E1-01 | Modelo de temas bajo asignatura | MVP | 5 |
| SIA-E1-02 | Administración de temas | MVP | 5 |
| SIA-E1-03 | Pesos por profesión y proceso SERUMS | MVP | 3 |
| SIA-E1-04 | Profesión del postulante para SERUMS | MVP | 2 |

**Fases:** todo MVP.
**Dependencias:** catálogos existentes (especialidades, asignaturas, procesos, proceso_asignaturas).
**Supuesto:** profesión = especialidad; área = asignatura; tema = nivel nuevo (ver README).
