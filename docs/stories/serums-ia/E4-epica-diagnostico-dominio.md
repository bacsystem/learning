# E4 Diagnóstico inicial y modelo de dominio

**Objetivo:** medir el nivel por área con pocas preguntas y mantener un modelo de dominio por área/tema que se actualiza con cada diagnóstico, práctica y simulacro.
**Valor:** el postulante sabe dónde está débil desde el primer día; alimenta dashboard, plan y repaso.

| Historia | Título | Fase | Pts |
|---|---|---|---|
| SIA-E4-01 | Test diagnóstico inicial por áreas | MVP | 5 |
| SIA-E4-02 | Resultado del diagnóstico | MVP | 3 |
| SIA-E4-03 | Modelo de dominio por área y tema | MVP | 5 |
| SIA-E4-04 | Actualización del dominio desde práctica y simulacro | MVP | 3 |

**Dependencias:** E3 (preguntas aprobadas y clasificadas), E1.
**Existente que se extiende:** practicas, simulacros, `pregunta_estadisticas`, desglose por asignatura.
